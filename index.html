앱 소개 / About this app

blogstudio uploader는 운영자가 직접 만든 영상을 운영자 본인의 YouTube 채널에 올리기 위한 내부용 도구입니다. 일반 사용자에게 제공되는 서비스가 아니며, 다른 사람의 계정에 접근하지 않습니다.

blogstudio uploader is an internal tool used by its operator to upload the operator's own videos to the operator's own YouTube channel. It is not offered to the public and does not access anyone else's account.

개인정보처리방침

1. 접근하는 정보와 용도

이 앱은 Google OAuth로 다음 권한을 요청합니다.

  • youtube.upload — 운영자 채널에 영상 업로드
  • youtube.force-ssl — 운영자 채널 영상의 자막·썸네일·재생목록·공개 예약 관리

이 권한은 운영자 본인 채널의 콘텐츠를 올리고 관리하는 데만 씁니다.

2. 수집하지 않는 정보

이 앱은 제3자(다른 YouTube 사용자·시청자)의 개인정보를 수집하지 않습니다. 광고·분석·추적 도구를 쓰지 않습니다.

3. 저장과 보안

OAuth 인증 토큰은 운영자 본인이 관리하는 서버의 비밀 저장소에 암호화해 보관하며, 외부에 전송하지 않습니다.

4. 공유·판매

Google 사용자 데이터를 누구에게도 공유·판매·양도하지 않습니다.

5. 권한 철회

언제든지 https://myaccount.google.com/permissions 에서 이 앱의 접근 권한을 철회할 수 있습니다. 철회하면 보관 중인 토큰은 더 이상 쓸 수 없습니다.

6. Google API 서비스 사용자 데이터 정책

이 앱이 Google API에서 받은 정보를 사용하고 다른 앱으로 전송하는 방식은 제한적 사용(Limited Use) 요구사항을 포함한 Google API 서비스 사용자 데이터 정책을 따릅니다.

Privacy Policy

1. Data accessed and why

This app requests the following Google OAuth scopes:

  • youtube.upload — upload videos to the operator's channel
  • youtube.force-ssl — manage captions, thumbnails, playlists and scheduled publishing for videos on the operator's channel

These permissions are used only to upload and manage content on the operator's own channel.

2. Data not collected

This app does not collect personal data from third parties (other YouTube users or viewers). It uses no advertising, analytics or tracking tools.

3. Storage and security

OAuth tokens are stored encrypted in a secrets store on a server managed by the operator and are not transmitted to any other party.

4. Sharing and sale

Google user data is never shared, sold or transferred to anyone.

5. Revoking access

You can revoke this app's access at any time at https://myaccount.google.com/permissions. Once revoked, stored tokens can no longer be used.

6. Google API Services User Data Policy

blogstudio uploader's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.
